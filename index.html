同步到 GitHub

  1. 1
    打开 GitHub 生成密钥的页面
    设置已经帮你填好了。如果要求登录，就登录 zjuchyoo 账号。
    打开 GitHub ↗
  2. 2
    把 Expiration 改成 No expiration
    在页面上方，默认是 “30 days”。改成永不过期，以后就不用再弄了（会出现黄色提醒，不用管）。
  3. 3
    拉到页面最底下，点绿色的 Generate token
    其他选项都不用动。
  4. 4
    复制 ghp_ 开头的那串字符，回来粘贴到下面
    粘贴后会自动连接。
密钥只保存在这台设备的浏览器里，不用另外记下来。以后浏览器被清理了，收藏不会丢，想修改时照这 4 步重新生成一个就行。请不要把密钥发给别人。
